## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public
GitHub issue.

Instead, report it privately by emailing
**[REPLACE_WITH_SECURITY_CONTACT_EMAIL]**. Include:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof of concept if available
- Any relevant logs, screenshots, or configuration details

You should expect an initial response within a reasonable timeframe. This
policy will be updated with specific response-time commitments once the
project has an active maintainer team.

## Disclosure Process

1. The report is triaged and its severity assessed.
2. A fix is developed and validated privately.
3. The fix is released, and the reporter is credited (if desired) once the
   issue is public.
