# Technology Decision Records (TDR)

## Purpose

This folder contains Technology Decision Records — approved documents that
define which technologies Commerce Core uses and why. Unlike ADRs, which
capture individual architectural decisions, TDRs specifically govern the
technology stack and its evolution.

## Contents

- [TDR-001-Tech-Stack.md](TDR-001-Tech-Stack.md) — Official technology stack for Commerce Core MVP (frontend, backend, database, testing, tooling)
