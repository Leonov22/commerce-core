# Product

## Purpose

This folder contains product architecture documentation: functional scope,
information architecture, navigation, user flows, and the administration
panel's structure. These documents define *what* the product does and how
users move through it, as the foundation for UX, frontend, backend, and QA
work.

## Contents

- [MVP.md](MVP.md) — Functional scope of the Commerce Core MVP (must/should/could/won't have)
- [SiteMap.md](SiteMap.md) — Storefront information architecture, URL structure, and access matrix
- [Navigation.md](Navigation.md) — Navigation systems (primary, utility, breadcrumb, footer, context) and their rules
- [UserFlows.md](UserFlows.md) — Primary business flows (browse, cart, checkout, login, admin actions) with error handling
- [AdminInformationArchitecture.md](AdminInformationArchitecture.md) — Administration panel structure, resource lifecycle, and shared UI patterns
