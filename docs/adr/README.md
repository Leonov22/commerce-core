# Architecture Decision Records (ADR)

## Purpose

This folder contains Architecture Decision Records — short documents that
capture a single architectural decision, its context, the alternatives
considered, and its consequences.

## Contents

- [0000-adr-template.md](0000-adr-template.md) — Template for new ADRs

## Conventions

- Each ADR is a separate file, numbered sequentially: `NNNN-short-title.md`.
- ADRs are immutable once accepted; a changed decision is recorded as a new ADR that supersedes the old one.
